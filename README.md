# EAV Gitwe TSS - Student Admission and Registration Management System (SARMS)

Uyu mushinga wubatswe hifashishijwe **React 19**, **TypeScript (.tsx)**, **Tailwind CSS**, na **Vite**.

---

## 🚀 Uburyo bwo gutangiza uyu mushinga kuri Mudasobwa yawe (Step-by-Step)

### Intambwe ya 1: Shyira Node.js kuri Mashini yawe
Niba utarayishyiramo:
1. Jya kuri: [https://nodejs.org](https://nodejs.org)
2. Manura version ya **LTS (Recommended for Most Users)**.
3. Kanda **Next > Next > Install** kugeza irangiye.
4. Genzura ko yagezemo neza: fungura **Command Prompt (cmd)** cyangwa **Terminal** wandike:
   ```bash
   node -v
   npm -v
   ```
   *(Ugomba kubona imibare nka `v20.x.x` cyangwa `v22.x.x`)*.

---

### Intambwe ya 2: Fungura Umushinga muri VS Code
1. Manura izi dosiye zose z'umushinga uzishyire mu gakapu (folder) kuri mashini yawe, urugero: `Desktop/eav-gitwe-system`.
2. Fungura **Visual Studio Code (VS Code)**.
3. Kanda **File > Open Folder...** maze uhitemo ako gakapu (`eav-gitwe-system`).

---

### Intambwe ya 3: Shyiramo porogaramu zikenerwa (Dependencies)
Fungura Terminal muri VS Code (kanda `Ctrl + ~` cyangwa `Terminal > New Terminal` hejuru), wandikemo iyi command:

```bash
npm install
```

*(Ibi biratwara umunota umwe cyangwa ibiri kugira ngo bimare kuzana `node_modules`)*.

---

### Intambwe ya 4: Tangiza Sisitemu (Run the Dev Server)
Mu gihe `npm install` irangiye, andika:

```bash
npm run dev
```

Uzahita ubona ubutumwa bugira buti:
```
  VITE v6.x.x  ready in 250 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

---

### Intambwe ya 5: Fungura muri Browser
Kanda kuri **`http://localhost:5173`** cyangwa uyikoporore muri **Google Chrome** yawe. 
Sisitemu ya EAV Gitwe TSS izahita yifungura igaragaza:
- Incamake y'imbogamizi 8 z'ikigo
- Kwakira abanyeshuri bashya
- Kugenzura ibyangombwa
- Gucunga amacumbi n'ibyumba (Blocks A-D)
- Kwishyuza amafaranga n'inyemezabwishyu
- Kohereza SMS ku babyeyi
- Gucapa amabaruwa yo kwemererwa kwiga

---

## 🛠️ Uko wahagarika cyangwa wakongera gutangiza
- **Kuyihagarika:** Kanda `Ctrl + C` muri Terminal ya VS Code.
- **Kongera kuyifungura ikindi gihe:** Fungura ako gakapu muri VS Code wandike: `npm run dev`.
